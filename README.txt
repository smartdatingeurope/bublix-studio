Bublix Studio Online — первая версия.
Файлы index.html, Bublix.glb и Bublix_reference.png должны находиться в корне репозитория GitHub.
GitHub -> новый публичный репозиторий -> Add file -> Upload files -> загрузить все три файла -> Commit changes.
Settings -> Pages -> Deploy from a branch -> main -> /(root) -> Save.
Подождать публикации сайта. Открыть URL, указанный в Pages.
Для загрузки внешних библиотек Three.js нужен интернет.
Функции ИИ и Supabase пока НЕ подключены. В этой версии есть просмотр GLB, загрузка локальных файлов, снимок кадра и скачивание GLB.
