🖼️ Цвета по картинке

Образец цветов — виден прямо в программе
Программа определяет основные цвета изображения. Выбери цвет, затем деталь модели и нажми «Применить к детали».Подбирает цвет для отдельных мешей по названиям (глаза, уши, лапы и т. д.) и палитре образца. Если модель цельная, детали определить нельзя.

🧠 Локальный ИИ — сценарист

Бесплатная модель Qwen3 через Ollama на твоём компьютере. Создаёт сценарии, диалоги и идеи для мультфильмов; не создаёт видео.
Ollama должна быть запущена на этом компьютере. Для доступа с GitHub Pages может потребоваться разрешить адрес сайта в настройке OLLAMA_ORIGINS и перезапустить Ollama.

🤖 ИИ-помощник по рисунку

Подключение к совместимому с OpenAI Vision API. Требуется доступ к модели и её API-ключ. Без подключения остальные функции студии работают как раньше. Ключ используется только в текущем окне и не сохраняется в проекте.
ИИ анализирует изображение и выдаёт схему раскраски. Применить её к цельной сетке GLB без отдельных деталей автоматически пока нельзя.

🎞️ Монтаж клипов

Фрагменты воспроизводятся по порядку и записываются в единый файл. Звук клипов включается в запись, когда браузер это поддерживает. Для длинных роликов потребуется достаточно памяти.
Автоопределение цветов не означает автоматическое распознавание частей персонажа. Работает без Python. При открытии требуется интернет для загрузки бесплатного 3D-движка Babylon.js. Точное определение отдельных деталей цельной модели пока недоступно. Монтаж клипов доступен в экспериментальном режиме. MP4 экспортируется только при поддержке кодека браузером, иначе WebM.
